| Command             | Variable(s)        |
| ------------------- | ------------------ |
| `CatchPokemon`      | `specimen`         |
| `ChangePokemonForm` | `specimen`         |

| `ReleasePokemon`    | `specimen`         |
| `SwapPokemon`       | `source`, `target` |
| `TradePokemon`      | `source`, `target` |
